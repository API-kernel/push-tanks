# 🚜 Tank 1990 Online

Современный многопользовательский ремейк классической игры **Battle City** (Танчики) для браузера.
Поддержка PvP, Co-op, игры с мобильных устройств и геймпадов.

🚀 **LIVE DEMO:** [https://tanks.alex-pushkin.ru/](https://tanks.alex-pushkin.ru/)

![Screenshot](https://img.shields.io/badge/Node.js-server-green) ![Screenshot](https://img.shields.io/badge/Socket.io-Realtime-blue) ![Screenshot](https://img.shields.io/badge/Canvas-Rendering-orange)

## ✨ Особенности

*   **Мультиплеер:** Играйте с друзьями или случайными игроками. Лимит активных танков задаётся для каждой команды.
*   **Командные бои:** Желтые vs Зеленые. Балансировщик команд.
*   **Режим "Spectator":** Если места в командах нет, вы становитесь зрителем и можете наблюдать за боем.
*   **Quick Play:** Умный матчмейкинг — находит активную игру или создает новую и сразу запускает её.
*   **Локальный Кооператив:** Возможность добавить второго игрока на том же компьютере ("Add Local Player").
*   **Кроссплатформенность:**
    *   💻 **PC:** Клавиатура (WASD / Стрелки).
    *   🎮 **Геймпады:** Поддержка D-Pad, стиков и осей (включая специфичные оси 9/10).
    *   📱 **Mobile:** Сенсорное управление (виртуальный стик и кнопка огня).
*   **Улучшенный движок:**
    *   Серверная физика (авторитарный сервер).
    *   Клиентская интерполяция и анимации (плавные 60 FPS даже при лагах сети).
    *   Pixel-perfect коллизии и отрисовка.
    *   Адаптация скорости под любой FPS сервера.

## 🎮 Управление

| Действие | Игрок 1 (Yellow) | Игрок 2 (Green) | Геймпад |
| :--- | :--- | :--- | :--- |
| **Движение** | `W`, `A`, `S`, `D` | `Стрелки` | `D-Pad` / `Стик` |
| **Огонь** | `SPACE` | `ENTER` / `NumEnter` | `A` / `X` / `B` |
| **Статистика** | `TAB` | `TAB` | `Select` / `Back` |
| **Пауза** | `P` | - | `Start` |

На мобильных устройствах управление появляется автоматически.

## ⚙️ Функционал Лобби

Хост комнаты может настраивать параметры игры:
*   **Map:** Выбор уровня.
*   **Auto Random Map:** Случайная карта после победы.
*   **Max Active Tanks:** Лимит танков на команду (лишние игроки уходят в зрители).
*   **Bots:** Настройка количества ботов для каждой команды.
*   **Hot Join:** Разрешить вход в уже идущую игру.


## 🤖 Тактический AI

В лобби **BOT AI** выбирает тактических ботов (**TACTICAL V5**, по умолчанию),
предыдущие версии V2/V1 или исходных случайных (**CLASSIC**). Боты распределяют
командные задачи, защищают и атакуют базы, собирают бонусы, берут упреждение,
уклоняются, прикрывают базу и адаптируются к вооружению противника. Игроки и боты
с одинаковыми характеристиками имеют одинаковый приоритет целей.

Запуск: `npm install`, затем `npm start`. Проверки: `npm test`.
Прямое сравнение: `npm run ai:benchmark -- --candidate tactical-v5 --baseline tactical-v2 --maps 1,7,Bunker --seeds 101,202,303`.
Парная лестница против фиксированных соперников: `npm run ai:evaluate -- --candidate tactical-v5 --reference tactical-v2 --suite release --output /tmp/ai-release.json`.
Стенд работает параллельно на доступных CPU; политики прошлых версий защищены
контрольными суммами. ML-сервер для игры не требуется.

В лобби также доступны **V6/V7 (LAB)**: исправления разъезжания и прогноза,
экспериментальная защита базы по времени перехвата и сбор бонусов ради ремонта.
Они проверены против V5 и фиксированных соперников; устойчивого превосходства
пока нет, поэтому **V5 остаётся основной**. Отдельные компоненты сравнивает
`npm run ai:ablate`, новые реактивные сценарии — `npm run ai:challenge`.
